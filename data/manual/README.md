# Manual data

Files typed in by hand from public documents. There's no API for these sources. Each row keeps its source URL.
These files are committed to Git, unlike `data/raw/`, which the scripts regenerate.

| File | Content | Collected |
|------|---------|-----------|
| `lvmh_selective_retailing_financials.csv` | LVMH Selective Retailing revenue & profit from recurring operations (M€), from LVMH annual results press releases. Separator `;`, French number format (`14 852`). **Note:** Selective Retailing = Sephora + DFS + Le Bon Marché; LVMH does not publish Sephora alone. | 2026-11-11 |
